# Documentation Unification Map

This document aligns the major project documents:

- `README.md`: user-facing overview, install, quickstart, CLI usage.
- `DESIGN_OVERVIEW.md`: architecture rationale.
- `IMPLEMENTATION_PLAN.md`: execution-level implementation tracking.
- `ROADMAP_PROGRESS.md`: checklist status and current focus.
- `docs/API_STABILITY.md`: semver and deprecation policy.
- `docs/GOVERNANCE.md`: compliance and security guidance.

## Source of Truth
